# 双层PPO实验方案

## 一 数据与时间安排

| 用途 | 当前安排 |
| --- | --- |
| 训练与模型对比 | 2025年7月1日起，覆盖2025年后期和2026年，所有算法共用滚动任务 |
| 行情截止 | 从公司ClickHouse自动取得最近已收盘的可用行情，上限为2026年12月31日 |
| 最新评分信号 | 截止日前第20个交易日，未来20日收益标签完整后才参与评价 |
| 算子预热 | 首个任务之前额外读取100个交易日，默认从2025年1月27日起 |

各任务依次执行F定方向、G生成、A观察、R奖励，每段20个信号交易日，等待前段标签成熟后衔接，每10日滚动。模型对比使用这些训练任务，记录训练期效果。实际日期和任务数以数据库快照及生成协议为准。后续独立检验使用新增行情和显式future任务。

## 二 实验方案

1. **生成算法对比实验。** 统一筛选器，比较原RPN自回归PPO、随机合法编辑、仅预训练扩散、原生RPN扩散PPO及GP。原RPN另比原奖励与统一质量成本奖励。

2. **上层算法对比实验。** 固定同一候选池，比较随机、IC排名、前向选择加交换、LinUCB、Double DQN、PPO。

3. **上下层搭配实验。** 上层PPO分别接原RPN PPO、随机编辑、GP和新扩散下层。整体比较旧双PPO、新下层加常规筛选和新双PPO。

4. **上层奖励消融。** 比较三项完整上层奖励与分别去掉稳定性、成员质量扣分的版本。Top50净收益与超额作为选股效果评价指标。

5. **训练与速度对比实验。** 比较只续训下层、只续训上层、交替续训。同一成员集合另比等权与Ridge。

各学习组3个配对种子，按上述顺序先短训筛选、再对主要对比的实验组进行长训练。统一数据和搜索预算，分别记录训练、预处理及搜索成本。计划训练1至2周，长训节点范围按short结果、实际任务数与时间预算确定。
