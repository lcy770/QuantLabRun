# 双层PPO实验方案

## 一 数据与时间安排

| 用途 | 当前安排 |
| --- | --- |
| 训练与模型对比 | 从2024年1月2日起的同一组45个滚动任务，使用截至2026年6月16日的信息 |
| 最新训练信号 | 最晚2026年5月19日，未来20日收益标签在6月16日成熟 |
| 后续独立检验 | 使用2026年6月16日之后新增行情，另行配置验收任务 |

每个任务内仍按F定方向、G生成、A观察、R计算奖励依次执行，每段20个信号交易日，等待标签成熟后衔接。模型对比复用这些训练任务，结果标记为训练期效果。2023年7月3日起的数据只提供前置算子预热。

实际数据准备发现8个整日缺失，分别为2026年2月27日、3月2日至6日、3月9日、4月28日。目标面板等待这些真实行情补齐，执行命令见本目录README。

## 二 实验方案

1. **生成算法对比实验。** 统一筛选器，比较原RPN自回归PPO、随机合法编辑、仅预训练扩散、原生RPN扩散PPO及GP。原RPN另比原奖励与统一质量成本奖励。

2. **上层算法对比实验。** 固定同一候选池，比较随机、IC排名、前向选择加交换、LinUCB、Double DQN、PPO。

3. **上下层搭配实验。** 上层PPO分别接原RPN PPO、随机编辑、GP和新扩散下层。整体比较旧双PPO、新下层加常规筛选和新双PPO。

4. **上层奖励消融。** 比较三项完整上层奖励与分别去掉稳定性、成员质量扣分的版本。Top50净收益与超额作为选股效果评价指标。

5. **训练与速度对比实验。** 比较只续训下层、只续训上层、交替续训。同一成员集合另比等权与Ridge。

各学习组3个配对种子，按上述顺序先短训筛选、再对主要对比的实验组进行长训练。统一数据和搜索预算，分别记录训练、预处理及搜索成本。全部45任务的全量长训练与评价会超过两周，长训范围按short结果与实际预算确定。
