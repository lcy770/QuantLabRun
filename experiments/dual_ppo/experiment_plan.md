# 双层PPO实验方案

## 一 数据划分

| 用途 | 数据范围 |
| --- | --- |
| 模型训练 | 从2024年1月2日滚动27个任务，训练标签最晚不超过2025年9月24日 |
| 搜索与选模 | 用2025年历史生成与观察，2026年1月27日至3月3日反馈，标签截至3月31日 |
| 保留测试 | 2026年4月1日至5月19日信号，20日收益标签截至6月16日 |

现有行情覆盖至2026年6月16日，2023年7月3日起的数据用于至少100个交易日的算子预热。每个训练任务依次划分F定方向、G生成、A观察、R反馈，各20个信号交易日，等待前段标签成熟后衔接。2026年3月31日冻结方法与超参数。保留测试约一个半月，数据沿用现有研究股票池与口径。

2026年11月17日完整准备检查发现8个整日缺失，分别为2026年2月27日、3月2日至6日、3月9日、4月28日。日期方案已落实到程序，真实数据准备等待这8日行情补齐，执行命令见本目录README。

## 二 实验方案

1. **生成算法对比实验。** 统一筛选器，比较原RPN自回归PPO、随机合法编辑、仅预训练扩散、原生RPN扩散PPO及GP。原RPN另比原奖励与统一质量成本奖励。

2. **上层算法对比实验。** 固定同一候选池，比较随机、IC排名、前向选择加交换、LinUCB、Double DQN、PPO。

3. **上下层搭配实验。** 上层PPO分别接原RPN PPO、随机编辑、GP和新扩散下层。整体比较旧双PPO、新下层加常规筛选和新双PPO。

4. **上层奖励消融。** 比较三项完整上层奖励与分别去掉稳定性、成员质量扣分的版本。Top50净收益与超额作为选股效果评价指标。

5. **训练与速度对比实验。** 比较只续训下层、只续训上层、交替续训。同一成员集合另比等权与Ridge。

各学习组3个配对种子，按上述顺序先短训筛选、再对主要对比的实验组进行长训练。统一数据和搜索预算，分别记录训练、预处理及搜索成本。
