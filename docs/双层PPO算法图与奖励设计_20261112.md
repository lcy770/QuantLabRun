# 双层PPO算法方案

下层生成合格因子，上层选择适合等权组合的成员。

![算法总览](D:/Projects/Python/QuantLab-backtest/docs/双层PPO算法总览_20261112.png)

## 下层PPO

选起点，用RPN扩散编辑生成公式。通过合法性、指标和去重检查后入池。

**R下层 = Q + ηD − κC**

Q看IC、RankIC、ICIR距门槛的程度，越差越扣分。覆盖不足或公式无效扣分。C为生成评价耗时÷参考耗时，η、κ为权重。

## 上层PPO

根据独立验证表现逐个选因子，兼顾互补性，也可停止。方向提前固定，标准化后等权。

**R上层 = 组合预测分 − 稳定性扣分 − 成员不达标扣分 − 数量扣分**

预测分看后续组合IC，跨期波动越大扣分越多。

## 两层怎样连接

**D = 全池选出的平均分 − 移除该因子后重选的平均分**

用同一上层多次选择取平均。D反馈给下层，使它生成有助于组合的候选。

先训练下层 → 固定候选池训练上层 → 最后交替训练。
