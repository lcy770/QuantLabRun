## 当前算法

下层在同一个PPO内学习起点选择与原生RPN扩散编辑。连续单因子质量和实测成本形成基础奖励。

下层动作包括从最多32个短名单起点及NEW中选择，再执行完整RPN子式区间替换或NOOP。上层动作是选择未入选候选或STOP，常规配置候选池容量128、成员上限10。smoke使用更小规模检查执行。

```latex
R_L=Q-\kappa C
```

上层根据A段可见信息逐个选择成员或STOP，方向在F固定，每天标准化后等权。终点在R段计算三项奖励。

```latex
R_U=\alpha\overline{IC}-\beta\sigma_{block}-\gamma H
```

当前实现的H使用R段成员质量，配置为`member_segment=feedback`。三项权重初值为50、25、0.5，仍待实验标定。数量由最大10个成员和STOP控制。Top50收益用于评价。

成员贡献D按固定已选组合移除一个成员、剩余成员重新等权后的效用差计算。基础η=0，η大于0时作为联合反馈对照。

## 时间预算

long配置的16小时下层、8小时上层、4小时续训按每节点每训练种子记账。实际N个任务、3个搜索种子和1800秒预算，每个生成器每个训练种子的限时搜索需N×1.5小时，另有固定尝试搜索。19任务时约28.5小时。

全部节点的全量长训与评价会超过1至2周。先执行short比较，再确定long节点范围并单独核算总耗时。
