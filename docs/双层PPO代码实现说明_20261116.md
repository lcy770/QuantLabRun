## 算法与实际公式

下层对每个主候选执行起点或 NEW 选择、固定正向扰动、有限步原生 RPN 去噪编辑及真实金融评价。起点头和编辑头属于同一个 GeneratorPolicy，使用同一个优化器。每条轨迹包含起点动作及各步编辑动作，各动作保存自身旧概率。编辑概率等于位置概率乘该位置的条件替换概率。

基础下层终点奖励为

```math
R_L=Q-\kappa t/t_{ref}
```

```math
s(x,\tau)=\operatorname{clip}((x-\tau)/\tau,-1,1)
```

```math
Q=[s(IC,0.02)+s(RankIC,0.01)+s(ICIR,0.10)]/3-\max(0,(0.8-c)/0.8)
```

方向根据 F 段平均 IC 固定，IC 非负取 +1，否则取 -1。Q 和准入使用 G 段的有向 IC、RankIC、未年化 ICIR 及填充前覆盖率。ICIR 使用可计算日 IC 的总体标准差，标准差为零时记不可计算。非法、数值溢出或指标不可计算时 Q=-1。完全重复在候选入池时去重。按该原式，合法公式的 Q 可以低于 -1。

t 包含起点决策、扰动、编辑及实际评价。每批起点准备耗时按主候选数分摊。t_ref 使用训练前基准采集的中位数，记录后固定。κ 初值 0.05。实际缓存命中引起的耗时变化纳入真实成本，实际耗时使后续采样具有硬件相关性。

每个因子在每日自身有效股票上标准化，缺失值和零方差截面填零，成员权重固定 1/K。单因子指标在填零前计算。

```math
P_{t,i}=\frac1K\sum_{j\in S}d_j z_{j,t,i}
```

上层中间步骤奖励为零，完整集合终点奖励为

```math
U(S)=\alpha\overline{IC}-\beta\sigma_{block}-\gamma H
```

```math
H=\frac{1}{4K}\sum_{j\in S}\sum_{m=1}^{4}\operatorname{clip}((\tau_m-x_{j,m})/\tau_m,0,1)
```

τ 依次为 0.02、0.01、0.10、0.80。不可计算项欠缺度记 1。组合每日 IC 不可计算时记 0 并报告比例，每 10 个交易日组成一个块，块均值使用总体标准差。尾部不足 10 日时作为一个块。空组合效用为 0。

Word 中 H 的文字同时出现搜索期和反馈期。本实现采用反馈期 R，配置为 reward.member_segment="feedback"。α、β、γ 初值为 50、25、0.5，属于尚待实验标定的初值。

上层观察只包含 A 段特征、共同有效股票上的有向相关性、已选成员和剩余名额。训练回报使用 R 段。已选成员被屏蔽，STOP 始终可用，到容量上限时回合结束。候选池容量默认 128，组合容量默认 10。

```math
D(f;S)=U(S)-U(S\setminus\{f\})
```

D 由上层评价器计算。移除后其余成员固定并重新等权，使用同一评价段及完整三项效用。联合反馈为

```math
R_L=Q+\eta D-\kappa t/t_{ref}
```

η 默认 0。η>0 时已选成员的贡献根据 proposal_id 回传到本批主生成轨迹，包括起点和所有编辑。未选提案以及背景池中的历史来源对本批 D 回传为 0。D 表示当前已选组合中的局部贡献。

## 时间与池的边界

每个训练任务显式配置 fit、search、validation、feedback，分别对应 F、G、A、R。前一段全部标签成熟后才能进入下一段。训练 R 标签须早于开发或测试的 G 段起点成熟。future 表示冻结选择后的独立验收，只在各选择方法完成后加载。

起点池逐批提交合格公式及 G 段质量成本统计，R 段贡献不会直接成为下一次起点观测。候选池按规范式和精确信号身份去重，容量不足时按 G 段 Q 排序保留。全部合格发现与最终供上层选择的容量内候选分别记录。

训练顺序为结构初始化、下层训练、生成并冻结各任务候选池、上层训练、交替训练。交替轮先固定上层计算本批生成贡献并更新下层，随后用更新后的下层重新生成候选，再采集并更新上层。检查点保存生成器版本、选择器版本、候选池、优化器、随机状态及成本尺度。

主要输出包括 resolved_config.json、cost_calibration.json、progress.json、training_state.pt、lower_base.pt、upper_frozen_final.pt、joint_final.pt、逐次生成日志、两层曲线、概率重放轨迹、candidate_pools、contributions、trials 和 portfolios。
