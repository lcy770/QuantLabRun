# 双层PPO实验方案

## 一 数据划分

采用历史时点中证500日频数据，预测未来20个交易日收益。补充2024年末100个交易日仅作指标预热。

| 用途 | 数据范围 | 使用方式 |
|---|---|---|
| 模型训练 | 2025年1月2日至2026年6月30日 | 滚动训练上下层，训练奖励所用20日标签最晚6月30日成熟 |
| 搜索与选模 | G为2026年1月5日至6月1日，A为7月1日至8月3日 | 按8月31日已知信息搜索、筛选和选模，封存公式、方向与选股规则 |
| 独立验收 | 信号为2026年9月1日至10月14日，标签和净值回放至11月11日 | 固定方法评价预测与选股效果 |
| 最新搜索 | 封存验收后，更新至2026年11月11日的信息 | 用截至10月14日已成熟标签重新搜索，供后续纸面选股跟踪 |

G用于下层生成和评价，A提供上层可见指标。训练中的后续段已用于奖励，独立验收继续保留。各窗口等待20日标签成熟后衔接。

## 二 准备做哪些实验

1. **生成算法对比**。统一筛选器，比较原RPN自回归PPO、随机合法编辑、仅预训练扩散、原生RPN扩散PPO及GP。原RPN另比原奖励与统一质量成本奖励。

2. **新颖性消融**。RPN自回归和扩散PPO分别比较有、无新颖性奖励。另在同一候选流比较旧近相关接纳规则开关，完全重复均去重。

3. **上层算法对比**。固定同一候选池，比较随机、IC排名、相关性过滤、前向选择加交换、LinUCB、Double DQN、监督集合评分加束搜索、PPO。

4. **上下层搭配**。上层PPO分别接原RPN PPO、随机编辑、预训练扩散、GP和新扩散下层。整体比较旧双PPO、新下层加常规筛选和新双PPO。

5. **上层奖励消融**。比较完整上层奖励与分别去掉稳定性、成员质量、数量扣分的版本。Top50净收益与超额作为选股效果评价指标。

6. **训练与速度对比**。比较只续训下层、只续训上层、交替续训，及2/4步编辑、缓存批量开关。同一成员集合另比等权与Ridge。

各学习组3个配对种子，按上述顺序先短筛、再对主要组长训。统一数据和搜索预算，分别报告训练、预处理及搜索成本。
