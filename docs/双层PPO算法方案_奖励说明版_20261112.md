# 双层PPO算法方案

下层生成合格因子，上层选择适合等权组合的成员。

![算法总览](D:/Projects/Python/QuantLab-backtest/docs/双层PPO算法总览_20261112.png)

## 下层PPO

起点池是待编辑公式库，包含基础变量、算子构造的初始公式及此前达标去重的公式。新建选项从基础表达式开始。下层按公式和指标输出选择概率，再做RPN扩散编辑，批末更新库。

**R下层 = Q + ηD − κC**

Q为搜索质量。IC、RankIC分别取逐日Pearson、Spearman相关均值，ICIR为日IC均值÷标准差。方向在更早历史固定，三项门槛τ依次为0.02、0.01、0.10。

**s(x, τ) = clip((x − τ)/τ, −1, 1)**

**Q = (sIC + sRankIC + sICIR)/3 − max(0, (0.8 − c)/0.8)**

各项s按对应指标和门槛计算，clip限制到−1至1。c为应评价股票日期对中，因子与标签均有效的比例。覆盖率不足80%时扣分。公式非法或指标不可计算时，Q取−1。

C＝t/t_ref。t含选起点、扩散编辑和公式评价，t_ref用训练前固定基准任务耗时的中位数，校准后锁定。独立训练η＝0并跳过D，联合暂设η＝1、κ＝0.05。

D见下文，总奖励同时训练起点选择与编辑。覆盖扣分、参考耗时及M为拟用设置。

## 上层PPO

观察独立验证指标、因子间相关性和已选成员，逐个选择或停止。方向提前固定，标准化后每个成员权重为1/K，K为入选数量。

**R上层 = 组合预测分 − 稳定性扣分 − 成员不达标扣分 − 数量扣分**

预测分看后续组合IC，跨期波动大、成员不达标或数量过多均扣分。选完后给连续奖励，训练因子搭配能力。

## 两层怎样连接

**D = 全池选出的平均分 − 移除该因子后重选的平均分**

固定同一上层，完整池与移除该提案后的池各选择M次，平均上层奖励之差为D，首轮暂设M＝2。移除后得分下降越多，D越大。未入池或重复提案D＝0。

先单独训练下层，再固定候选池训练上层。最后交替，先固定上层计算D并更新下层，再用新候选更新上层。
