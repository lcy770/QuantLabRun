## 3. 当前算法和实际训练配置

当前实现的流程为上层选择已有公式起点或 NEW，下层进行两步 AST 扰动与反向编辑，真实评价主候选，更新公式档案与容量为 5 的 Ridge 组合，再给上层反馈。

下层使用拟合期奖励。完成本次动作后，按旧策略继续生成多个终点，以真实终点奖励的均值估计动作价值。

\[
R(f)=0.5|IC_{fit}(f)|+0.3|RankIC_{fit}(f)|+0.2\tanh(|ICIR_{fit}(f)|).
\]

上层每生成一条主候选，根据有效新因子数量增量和搜索期保留组合 IC 增量获得奖励。

\[
r_k=n_k+50(B_k-B_{k-1}),\qquad \sum_k r_k=N+50(B_{end}-B_0).
\]

这里的 `n_k` 为本次新增有效、非重复因子的指示值，`B` 为搜索期保留组合的 IC。后续评价固定公式、方向和组合权重。

| 设置 | 本轮实际值 |
|---|---|
| 行情数据 | 500 只股票、7 个字段，数据截至 2026-02-13 |
| 预测目标 | 未来 20 个正式交易日收益 |
| 历史任务 | 8 个训练任务、2 个开发任务、2 个测试任务 |
| 每任务区间 | 拟合期 120 日、搜索期 60 日，测试另有后续 60 日 |
| 主模型训练种子 | 0、1、2 |
| 下层训练 | 128 批，每批 64 条公式，2 步编辑 |
| 下层续采样 | 每批 16 个状态，每状态 4 个终点 |
| 上层训练 | 48 批，每批 24 个回合，每回合 15 秒 |

初始五因子池的锁定后续平均 IC 为 -0.00984。上层主方案 12 次测试的 81 条发现记录中，后续达标 1 条。发现数按每次试验独立计数，跨试验的同一表达式可能重复出现。

需要接着解决以下问题。

1. 上层策略接近均匀。33 个动作的均匀熵为 3.4965，三个种子最后十批的平均熵约为 3.4949、3.4742、3.4941。每个训练回合平均只有约 12 至 14 次选择，重复扩展已访问起点约占 6.5% 至 7.8%。
2. 联合工作模型难以积累更新。18 次候选更新中 13 次同分、5 次下降，全部回滚。最终固定下层版与交替版的上下层权重逐项相同。同分回滚可能阻止小更新积累。
3. 下层拟合奖励与新发现价值存在差距。重复结果的拟合奖励均值约为 0.123 至 0.134，合格发现约为 0.135 至 0.137。金融训练后的随机起点组搜索数量提高，后续达标表现没有相应改善。结构初始化对照只有一个初始化，应继续通过开发任务核验。
4. 搜索期组合改善跨期失效。所有方法的平均后续组合 IC 均低于初始池。需要检查反复依据搜索期成绩选择成员带来的跨期不稳定。
5. Ridge 成本很低。上层 45 秒试验中的组合评分平均约 0.0044 秒，主要生成开销在 AST 合法动作枚举和编辑。

本轮只有三个独立训练种子，历史后续区间此前已经查看过，结果属于回顾性复验。退市历史完备性、现金分红与再投资口径仍需认证。搜索期合格、后续达标和组合后续 IC 分别记录。

### 9.8 几轮结果放在一起怎样判断

| 问题 | 已有观察 | 下一窗口可继续核查的内容 |
|---|---|---|
| 更好的初始因子库是否足以解决问题 | 16 条扩为 402 条后发现数量有所变化，重验为 401 条和 399 条后，上层优势和后续有效性仍未稳定出现 | 固定数据、起点和下层，单独比较调度策略的贡献 |
| 工程加速是否成立 | 条件动作采样、增量 Ridge、批量查重和 AST 剪枝均有数值或轨迹验证 | 在下一轮完整训练和搜索中记录实际节省的时间 |
| 上层是否真正学到起点价值 | 修复轮保留第 0 次，GAE 轮保留第 20 次，最新三个模型为第 40、0、24 次，最新策略熵仍接近均匀 | 分析奖励稀疏度、优势方差、重复扩展机会、状态输入与开发选择标准 |

| 下层训练是否改善后续因子 | 拟合奖励上升，多个时期的后续因子和组合表现仍较差 | 滚动开发任务检查拟合奖励与后续发现的关系，再决定训练或奖励改法 |

| 是否只是训练规模不足 | 已做较长 RPN 基线、较大起点库、更多历史任务、三个模型和长回合补充 | 先定位学习和评价机制，再用预定对照检验扩大规模的增量效果 |
