# 双层PPO实验方案

本轮用2026年数据，按先下层、再上层、最后联合的顺序，验证新分工是否提高有效因子的发现速度和等权组合表现。计划在公司RTX 4060上运行14天。

## 一 数据和评价规则

更新日频行情至2026年11月11日并冻结快照。采用按历史时点构建的中证500股票池，包含成分变更和退市记录。输入为开高低收、成交量、成交额和换手率，预测未来20个交易日收益。补充2025年数据，供早期任务、使用方向确定和时序算子回看。

| 用途 | 信号日期 | 标签最晚结束日 |
|---|---|---|
| 训练反馈 | 2026年1月5日至6月1日 | 6月30日 |
| 开发和模型选择 | 2026年7月1日至8月3日 | 8月31日 |
| 最终保留测试 | 2026年9月1日至10月14日 | 11月11日 |

每个滚动任务依次设置生成、独立验证、后续反馈三段，各20个交易日。前段收益标签成熟后再进入下一段，每10个交易日滚动。使用方向在更早历史确定，上层只看独立验证段信息。全部方法统一标准化后等权组合。

当前已核验缓存截至2026年2月13日，先补齐数据并核对标签日期。最终测试约26个评分日，统计不确定性，后续继续检验。

## 二 对比实验顺序

| 顺序 | 具体对比 | 要回答的问题 |
|---|---|---|
| 1 程序核验 | 标签时间、RPN合法性、等权计算、去重、旧动作概率重放 | 数据和PPO更新是否正确 |
| 2 下层独立实验 | 随机合法编辑、仅结构预训练、旧奖励下层、新质量成本奖励下层 | 下层训练是否更快生成合格候选 |
| 3 上层独立实验 | 同一冻结池上比较随机、IC排名、相关性过滤、前向选择加交换、上层PPO、监督集合评分加搜索 | 上层是否比普通筛选选得更好 |
| 4 两层连接实验 | 独立训练双层、只续训下层、η＝0交替训练、η＝1交替训练 | 收益来自续训、上层更新还是贡献反馈 |
| 5 速度与配权 | 逐项启用缓存和批量计算，2步与4步编辑，同一集合比较等权与Ridge | 提速是否增加产出，配权是否影响结论 |
| 6 完整系统 | 原双层PPO、新下层加最佳常规筛选、新双层PPO | 新分工和双层连接有没有实际收益 |

各学习组用3个配对种子，相同数据、起点库、初始化和门槛。续训组从相同检查点开始，追加预算一致。普通筛选只用相同可见验证数据，最终测试在模型与参数固定后执行。

## 三 训练安排

主设备为公司RTX 4060，CPU并行评价公式。先实测CUDA、显存和每小时更新量，再按单机顺序执行。

| 时间 | 任务 | 训练预算 |
|---|---|---|
| 第1至2天 | 补齐2026年数据，完成新分工实现、正确性和吞吐检查 | 准备与检查 |
| 第3至6天 | 下层旧奖励与新奖励两组，各3个种子 | 2×3×16小时＝96小时 |
| 第7至10天 | 上层PPO与监督集合评分两组，各3个种子，复用冻结池 | 2×3×16小时＝96小时 |
| 第11至13天 | 只续训下层、η＝0交替、η＝1交替三组，各3个种子 | 3×3×8小时＝72小时 |
| 第14天 | 锁定模型测试，保存曲线、因子和对比结果 | 评价与汇报 |

**主模型每个种子累计约40小时，全部训练对照合计264设备小时。** 每2小时保存检查点，在约2、4、8、16小时检查开发曲线，各组采用一致的选模规则。随机、排名和搜索对照记录实际运行成本，速度测量计入预计算、失败和重复尝试。

## 四 首轮固定设置

| 项目 | 初始设置 |
|---|---|
| 候选和组合规模 | 候选池128，最多选10个，扩散编辑比较2步和4步 |
| 单因子门槛 | 有向IC≥0.02，RankIC≥0.01，ICIR≥0.10，覆盖率≥80% |
| 下层奖励 | R下层＝Q＋ηD－κC。独立训练η＝0，联合暂设η＝1，κ＝0.05 |
| Q与C | Q为三项指标相对门槛的连续得分均值，各项截断至−1到1，覆盖不足再扣，公式或数值无效时Q＝−1。C为生成评价耗时÷参考耗时 |
| D组合贡献 | 完整池选出的平均组合得分，减去移除该因子后重新选择的平均得分。两次使用同一上层版本、多次选择取均值 |
| 上层奖励 | 平均组合IC÷0.02－0.5×时间块IC标准差÷0.02－0.5×成员平均质量欠缺度－0.05×成员数÷10 |

质量欠缺度按各项低于门槛的不足比例取0到1后求均值。稳定性按连续10个交易日分块。空集合奖励为0。上述系数与规模在开发实验核验后固定。计算D时固定本批起点档案和上层参数，独立采样候选，批末统一更新档案。

## 五 最后交付什么结果

**下层看产出，上层看筛选，两层看连接收益。** 同时报告固定尝试数和固定时间结果，记录合格非重复数、后续达标数、组合IC和RankIC、跨期稳定性、统一交易规则下扣成本表现。

保存每组真实训练时长、候选数、更新数、GPU利用率和分步耗时，附训练曲线、3个种子差异及最终公式清单。根据开发曲线判断是否追加训练，并用独立测试评价最终方案。

数据日期依据[上交所2026年休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)核定，落地时再次核对完整交易日历与标签成熟时间。
