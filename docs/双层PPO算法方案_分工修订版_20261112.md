# 双层PPO算法方案

下层生成合格因子，上层选择适合等权组合的成员。

![算法总览](D:/Projects/Python/QuantLab-backtest/docs/双层PPO算法总览_分工修订版_20261112.png)

## 下层PPO

下层学习选起点和RPN扩散编辑，生成合法、达标、非重复的候选。起点池保存初始合法公式及此前合格公式，新建选项从基础表达式开始。起点池在批末更新。

**R下层 = Q − κC**

Q为搜索质量。IC、RankIC取逐日截面相关均值，ICIR为日IC均值÷标准差。方向在更早历史固定，三项门槛τ依次为0.02、0.01、0.10。

**s(x, τ) = clip((x − τ)/τ, −1, 1)**

**Q = (sIC + sRankIC + sICIR)/3 − max(0, (0.8 − c)/0.8)**

各项s按对应门槛计算，clip限制到−1至1。c为因子与标签样本覆盖率，低于80%扣分。公式非法、指标不可计算或规范化公式完全重复时，Q取−1。

C＝t/t_ref。t含选起点、编辑和评价耗时，t_ref为训练前基准任务耗时中位数，校准后锁定，κ暂设0.05。总奖励同时训练起点选择与编辑。

## 上层PPO

观察独立验证指标、因子间相关性和已选成员，逐个选择或停止。方向提前固定，标准化后每个成员权重为1/K，K为入选数量。

**R上层 = 组合预测分 − 稳定性扣分 − 成员不达标扣分 − 数量扣分**

预测分为后续平均有向IC÷0.02。稳定性按10日块IC波动扣分，成员不达标和数量过多也扣分。整组连续得分用于更新选取和停止的概率。组合评价由上层负责。

## 两层怎样连接

下层提供候选池，上层评价所选组合。整体效果以固定时间内的合格因子数和最终组合表现验收。

先训练下层 → 冻结下层和候选池训练上层 → 比较分别续训与交替续训。交替时重新生成候选并采集上层轨迹，两层各用自己的奖励。

成员贡献D的计算归上层评价模块，向下层反馈列为后续对照。待归因可靠、成本可控后，再检验R下层＝Q＋ηD－κC。门槛和系数均为待核验初值。
