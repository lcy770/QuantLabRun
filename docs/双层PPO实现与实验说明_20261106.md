# 双层 PPO 因子搜索：实现与实验说明

目标：在相同实际搜索时间内，发现更多有效、非重复的单因子，并提高它们组成的预测信号的 IC。

## 采用的算法定义

本次以用户提供的《单因子强化学习搜索方案_上层修订_20261104.docx》为执行依据，结合后续对组合计算缓存的讨论。

另一份《算法设计说明书.md》包含“固定参考池、共同发现奖励、下层跨公式共同回报”。这些与 Word 和用户随后明确要求保留的下层奖励冲突，因此本实现采用：

- 下层保持原来的真实单因子终点评分，以及固定本次动作后的多次续采样估计。不上移组合奖励，不把后续其他公式的发现奖励加入下层目标。
- 上层选择公式起点，使用有效发现数量和动态保留组合的 IC 改善。
- 保留 Markdown 中不冲突的机制：合法可逆 AST 扰动、结构去噪预训练、独立 Actor/Critic、NEW、公共短名单、真实概率重放、交替冻结、时序边界和成本记账。
- 两层因此通过“起点 → 生成分布 → 新因子 → 档案和组合”连接；不能声称它们对同一个共同奖励都做了无偏策略梯度。训练目标的这一差别必须在论文中写清楚。

`feat/standardize-web-project` 原本只提供 RPN MaskablePPO。树扩散和起点调度是本次加入的完整实现，原 RPN 入口保留作对照。

## 完整流程

1. 从有限、可配置的金融文法递归采样合法公式，不依赖只有几条固定模板的起点库。
2. 按树结构族划分训练、开发、结构留出集；构造四步可逆扰动和逆编辑标签。
3. 用逆编辑负对数概率训练下层 Actor。结构开发集选检查点，结构留出仅报告，不参与拟合和选点。
4. 用真实市场终点成绩训练下层 PPO；部分非终点动作采用续采样平均估计。
5. 所有调度器从相同初始档案和组合开始。上层选择起点或 NEW，下层完成一次扰动及反向编辑。
6. 对主候选做真实评价、去重，更新档案、组合与上层奖励。合法可靠但未达单因子门槛的公式仍可作为起点。
7. 完整搜索回合结束后计算上层累计回报，再更新上层 PPO。
8. 交替版本在上层更新后重新采集下层轨迹，用原下层奖励更新生成器，再重新采集下一轮上层轨迹。
9. 锁定训练结果，在开发任务及测试任务的搜索区间比较；最终未来区间只评价已锁定公式、方向、组合权重。

## 起点如何选择

档案记录公式 AST、单因子定向 IC、是否初始已知、扩展次数、平均上层扩展奖励、有效新因子发现率、重复率。

每轮用确定的轮换规则，从单因子质量、扩展产出、低访问次数、结构不同四类排序中交替取候选，去重后形成公共短名单。记录曝光次数，低访问候选不会因没有扩展成绩而永久消失。

Actor 编码候选 AST 及统计量，并汇总当前组合的 AST、权重和 IC；候选集合和组合均用集合汇总。Actor 输出短名单成员和 NEW 的概率。Critic 使用相同信息，但参数独立。剩余时间不作为网络输入，由环境执行终止。

NEW 用递归文法先验产生不在已知档案中的合法 AST。语法采样尝试有明确上限；耗尽时记录零发现尝试，不能凭空返回替代公式。NEW 只负责选择档案外的起点，不保证其经济价值。

NEW 同时排除已经用过的起点，避免“上次起点没进入结果档案，因此又被 NEW 抽到”。主候选仍须经过结构去重及真实信号去重；文法不同不能保证信号不同。

## 下层真实奖励及续采样

下层终点分使用已有单因子评价规则的三个组成量：绝对 IC、绝对 RankIC、绝对 ICIR 的 tanh，默认权重 0.5、0.3、0.2，仅来自拟合训练数据。数值不可靠的信号得 0。

下层评分使用独立的拟合期入口和有上限的标量缓存，不执行搜索期计算。改变或破坏搜索数据不能改变下层训练奖励。平台提供的拟合期 IC、ICIR 门槛仍用于发现验收，不参与改变下层奖励公式。

当前动作已经执行后，从其结果状态继续完成剩余编辑。默认 K=4 指总共四个终点：原轨迹终点加三条独立续采样。它们的真实终点评分取算术平均：

\[
\widehat Q(s,a)=\frac1K\sum_{j=1}^{K}R(f_j).
\]

继续采样按旧策略动作概率抽取，不枚举所有路径、不再额外乘动作概率。采样和续采样完成前不更新网络。最后一步直接用已得到的真实终点评分；未选中进行续采样的步骤使用原轨迹终点评分。

Actor 的联合概率是“编辑位置概率 × 该位置具体替换概率”。PPO 保存原始 AST、剩余步数及实际编辑，重算同一合法集合下的联合概率，采用一次联合概率比和一次裁剪。

## 上层奖励和组合评价

拟合期锁定因子方向，搜索期定向平均 IC 达到门槛且可靠、非冗余，记为一个有效新发现。公共初始公式、结构重复、等价信号不计新增。

高相关不直接判无价值。拟合期日度绝对相关均值超过阈值时，按实际配对组合 IC 增益判断是否包含新增信息；权重仍仅由拟合期得到。

\[
r_k=n_k+\lambda(B_k-B_{k-1}).
\]

初始组合仅按拟合期成绩及等价信号检查选择。容量是配置项，5 是示例，不代表最优。新因子合格后，组合未满时检查加入，已满时逐一检查替换。原组合始终参与比较，平分保留原组合。

组合模型是固定正则强度 Ridge。每日截面先标准化，拟合期按“每天同权、每天内股票同权”拟合；同一组权重应用于搜索期，计算每日组合 IC 后再求平均。组合 IC 不能用成员 IC 的平均替代。

为减少成本，缓存拟合期二阶统计量和搜索期逐日协方差。新因子只增量计算与当前成员、收益的关系，比较替换时复用小矩阵。只缓存当前组合及候选的组合统计，信号值另用有上限的 LRU 缓存。数值抵消严重时回退到稳定的原始组合信号评分。拟合期完全等价的因子按组正则化，避免重复信号削弱 Ridge 惩罚。

上层完整回合使用 γ=1，回报为之后实际发生的奖励总和。累计奖励严格等于有效发现数量加最终组合改善乘 λ。它不是各起点独占贡献的分解。

## 数据、预算和检查点

- 明确区分拟合、搜索反馈、最终未来区间，按每个标签的实际成熟日期检查边界。重叠默认拒绝；平台适配器在运行配置中明确裁去重叠的评分日期。
- 搜索回合计时包括初始档案评价、起点选择、扰动生成、真实评价、去重、组合计算与必要日志。截止后完成的主候选不获奖励、不入库；超时开销仍报告。
- 下层续采样仅用于其训练，不登记为上层发现；其真实评价与训练耗时计入训练成本。训练与搜索开销、从头训练成本分别报告。
- 组合评价计数在公共评价器中维护，包括近似去重的配对比较、没有改善的替换和超时未获奖励的比较，不只统计最终入池的方案。主候选日志另有 `credit` 事件，记录是否真正计入本轮奖励。
- 评价各方法创建独立冷缓存；公共准备和模型训练成本另外报告。不能把热缓存优势当作策略优势。
- 保存上下层模型、优化器、阶段进度、Python/NumPy/PyTorch 随机状态、实际数据文件指纹、配置和实现指纹。每批或每轮 epoch 原子提交检查点；从提交点恢复，未提交的尝试日志保留但不冒充已提交结果。
- 不同代码或数据指纹不能直接续训。修改算法后使用新的实验目录，保留旧结果。

## 实验与结果文件

`hierarchical_config.fullcheck.json` 用同一完整算法、较短训练和搜索预算执行首次真实数据检查，覆盖预训练、两层 PPO、交替、原 RPN、随机初始化 AST、随机/质量/产出/UCB 调度和 λ=0 的独立训练。它不能用于宣称充分训练或性能提升。

`hierarchical_config.example.json` 配合 suite 提供三次独立训练、300 秒搜索对照。阈值和预算是明确的起始实验规格，尚未证明最优。现有缓存未核实完整数据口径，因此默认是 exploratory。设为 formal 时必须通过数据口径检查，不能把旧缓存改个标记就当作已验证。

结果包含 progress.json、training_state.pt、结构验收、上下层学习曲线、每次主候选、每回合档案和组合、完整时间曲线、逐任务逐种子结果、CSV 汇总、跨种子区间估计和 accepted_factors.jsonl。零发现和失败也如实保存。

CSV 同时列出搜索耗时、该方法检查点所需的准备/预训练/下层/上层训练成本，以及未摊销训练成本的端到端发现速度。原 RPN 的初始化和在线 PPO 本身就在其搜索计时内。封闭未来期的复核属于报告开销，不参与搜索奖励。
