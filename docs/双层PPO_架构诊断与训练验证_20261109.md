# 双层 PPO 架构诊断与训练验证

## 当前结论

当前实验尚未实现更快发现有效、非重复且对后续组合有增量价值的综合目标。已定位并处理旧结构语料兼容性及重复子树位置不可辨识两项可复现缺陷，金融收益改善仍缺少稳定证据。

| 问题 | 本轮结论 |
|---|---|
| 改用 RPN 是否更好 | 序列编码的结构损失更低。固定尝试和限时金融结果不同，未显示速度优势。原生 token 编辑核尚待单独检验。 |
| 修改上层信用分配是否有效 | 即时回报增加了 30 秒发现数量，平均后续组合增量从整回合组的 −0.01491 变为 −0.09059，数量与组合价值发生取舍。 |
| 下层 PPO 是否有效 | 原金融训练提高部分搜索期产出，后续达标和边际价值尚未稳定受益。 |
| 层间连接与目标是否对齐 | 更新顺序、条件传递及概率重放均有核验。条件控制作用较弱，搜索期奖励一致性尚未迁移到后续价值。 |
| 位置编码是否解决问题 | 已解除原 Actor 的强制同分约束，但新增位置条件的金融对照未建立优势。 |
| 当前数据和训练时间如何判断 | 存在结构语料复用缺陷，行情标签抽样正确。短训练、状态可观察性和跨期反馈仍需分开检验。 |
| AutoDL 是否已使用 | 内嵌崩溃及普通浏览器策略阻断操作，无实例，费用 0 元。 |

### 搜索成绩到后续价值的断点

候选在搜索期被保留后，其后续组合表现经常下降，断点集中出现在跨期评价与组合保留之间。原奖励对合格非重复候选给数量分，即使它没有改善组合。当前加权奖励与三项条件交集的验收需要分别观察。

- Search completion 的 30 秒后续加权目标均值为 1.553，后续达标数量为 4.83，组合增量为 -0.06560。
- Historical forward completion 的 30 秒后续加权目标均值为 2.487，后续达标数量为 3.00，组合增量为 -0.01025。

历史后续反馈改善了上述限时加权目标与平均组合增量，但严格交集发现数从 1.67 降至 1.17。固定 32 次尝试的组合增量也没有改善。因此本轮选择继续研究反馈与组合保留规则，当前证据尚不足以支持仅扩大原奖励下的训练规模。

### 搜索截止点的敏感性

两轮反馈对照在六个种子任务中的实际候选共同前缀全部一致。种子 0、dev_0 的两次 30 秒试验，完成候选分别为 136 和 135 条，后续组合增量分别为 +0.09641 和 -0.00233。末尾候选能大幅改变保留组合，因此限时结果需要结合固定尝试、重复运行和配对种子阅读。

### 跨领域机制如何落地

资源选择中的下游价值反馈被转化为成熟历史时期的组合完成价值。持续子任务被转化为编辑全过程的起点与组合条件。层次非平稳性通过下层更新后重新采集上层处理。从栅格决策迁移到程序编辑时，还需要保留位置身份，重复子树的同分约束说明仅有内容表示不足以执行不同位置的任务。

现有下层状态主要描述程序结构、剩余步骤和少量组合信息，对当前金融窗口的数值关系表达有限。这是条件作用弱及回报难预测的一项待验证解释。位置编码与更多更新尚不能替代对反馈跨期稳定性及状态信息的检验。

### 下一轮最小配对实验

先固定生成器及候选流，只改变组合接纳依据。对照沿用搜索期增量，处理组要求在决策前已经成熟的多个历史验证窗口上具有正边际价值。各窗口的方向和权重仅在对应拟合段确定。当前已复用开发期的回放用于排除无效方案，新的金融验收预先锁定尚未参与调参的时期。后续标签继续只用于事后验收。

接纳规则在固定候选流中通过后，再固定上层，比较与该规则一致的下层终点反馈。沿用三个配对种子、相同起点和随机流，分别检验固定尝试与串行限时。主指标为搜索合格非重复、后续单因子合格及后续边际组合增量为正的交集数量，搜索总数和最终组合 IC 单独报告。

只有严格交集与独立历史验证随更新同步改善时，才追加更新批数。随后比较冻结下层的上层调度，最后再进行完整联合双层训练。当前位置修复、历史后续反馈和持续任务条件的组合金融效果仍待该联合验收。

## 本轮处理的六项问题

本轮先保存结果并修正统计，再固定上层检验下层，回放局部及组合价值，随后分别训练 RPN 表示对照和上层信用分配对照。根据价值链诊断增加历史后续完成反馈，进一步核查并修复重复子树的位置不可辨识问题。四组机制对照共新增 24 个离线训练版本。各轮计时均在训练、审计和回归结束后串行执行。

## 训练语料问题与恢复

重新训练前发现，旧结构语料 512 条原始公式中有 93 条不符合当前数值合法性规则，2,048 条逆向标签中有 907 条不在当前编辑核。旧读取只核对配置摘要，未验证复用语料是否仍符合编辑语义。当前读取入口会检查原式、扰动态、逆向结果及动作支持。

首次新对照尚未更新模型即失败，全部初始状态和失败源码归档。后续从原家族划分中选取相同的 96 条合法训练式、24 条检查式、24 条保留式，重新生成全部逆向标签。旧语料及模型保留。金融 PPO 的起点来自已验证公共库，旧结构语料对历史初始化的影响尚未单独隔离。

行情输入与结构语料分别核验。此前未来收益标签的 992 项抽样独立复算最大误差为零。发现的整市场换手率零占位主要发生于 2025 年，当前 2023—2024 年训练开发输入未受该项修复影响。完整时点一致性仍待认证。

此前资源争用曾使部分回合只完成 25 至 43 次尝试，已隔离恢复。第二阶段三次受回归任务干扰的计时已替换，废弃计时为 139.88 秒。第三阶段导入失败时更新数为零，废弃启动为 274.09 秒，其初轮计时也已整体隔离并用电源记录完整的串行结果替换。检查点阶段误读只影响报告元数据，现已更正。首次新表示训练也在零更新时因旧语料不兼容而失败，恢复使用独立重建语料。

## 结论适用范围与云训练

当前开发时期已反复用于研究及部分检查点选择，全部结果属于回顾性开发诊断。每个对照只有三组配对训练种子，重复采样及不同模型版本不作为独立金融样本。数据完整时点一致性尚未认证。八批机制筛查未建立收敛结论。

各下层批次可来自不同历史任务，其终点回报曲线包含任务差异。当前位置与历史后续反馈对照冻结上层，用于隔离下层贡献。新部件组合成完整联合双层训练后的效果仍需独立验收。

AutoDL 官方地址的 HTTP 连接正常，Codex 内嵌页面持续崩溃。普通 Chrome 随后也因 computer-use 工具无法可靠确认当前网址而被浏览器策略停止。云实例选择与训练受此阻断。未创建云实例，费用为 0 元，授权上限为 20 元。
