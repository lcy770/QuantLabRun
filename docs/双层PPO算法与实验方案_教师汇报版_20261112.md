# 双层PPO因子生成与筛选方案

2026年11月12日

本研究拟提高固定时间内有效因子的发现数量，并选出适合等权组合的因子。下层PPO完成起点选择、RPN扩散编辑和候选生成，上层PPO从候选池中选择预测有效、表现稳定且相互互补的成员。本轮采用2026年数据开展训练和评价，安排约两周实验。

## 一 算法怎样运行

**下层生成候选 → 独立历史数据验证 → 上层挑选成员 → 标准化后等权组合 → 更晚历史数据评分。**

| 模块 | 具体操作 | 要学会什么 |
|---|---|---|
| 下层PPO | 自己选择已有公式或新起点，通过RPN扩散编辑生成公式，计算IC、RankIC、ICIR和覆盖率 | 用较少计算得到更多合格候选 |
| 上层PPO | 查看候选的验证表现、因子间相关性和已选成员，逐个选择因子，也可提前结束 | 从同一候选池选出更有效的组合 |
| 等权组合 | 每个因子按日做截面标准化，按早期历史确定使用方向，K个入选因子的权重均为1/K | 用统一规则检验选中成员的互补性 |

首轮候选池容量设为128，最多选10个成员，扩散编辑比较2步和4步。下层只把结构合法、数值可靠且搜索指标达标的公式交给上层。完全重复公式及等价信号去重，高相关且有差异的候选保留。上层在独立验证段再次检查候选质量。

## 二 上下层奖励函数

### 下层奖励

**R下层＝Q单因子质量＋ηD组合贡献－κC计算成本。**

Q综合有向IC、RankIC和ICIR。首轮合格门槛暂设为0.02、0.01、0.10，覆盖率至少80%。这些数值在开发实验中核验后固定。

每项指标得分按“实际值减门槛，再除以门槛”计算，限制在−1至1之间，三项取平均。覆盖不足再扣分，公式或数值无效时Q取−1。接近门槛和明显较差的候选由此获得不同反馈。方向在更早历史中确定，随后沿用。

C为生成和评价一个候选的耗时，除以预先测得的参考耗时。独立下层训练时η＝0。联合训练时暂设η＝1、κ＝0.05，并用对照实验检查。覆盖率低于80%时，按不足比例再扣分。奖励中取消新颖性分。

D通过完整候选池和移除候选后的结果计算。

**D(f)＝完整候选池经上层选择后的平均得分－移除f后重新选择的平均得分。**

两次均使用同一版本上层，多次选择后取平均，组合均采用等权。例如两次平均得分为0.8和0.6，则f获得0.2的组合贡献分。该分数加入下层总奖励，回传给生成f的起点选择和编辑动作。

### 上层奖励

**R上层＝组合预测分－稳定性扣分－成员质量扣分－数量扣分。**

| 项目 | 首轮计算规则 |
|---|---|
| 组合预测分 | 等权组合在后续反馈段的平均有向IC÷0.02 |
| 稳定性扣分 | 0.5×不同时间块组合IC的标准差÷0.02 |
| 成员质量扣分 | 0.5×入选成员的平均质量欠缺度 |
| 数量扣分 | 0.05×入选数量÷10 |

质量欠缺度按各项低于门槛的不足比例计算，每项限制在0至1后取平均。反馈段按10个交易日分块。上层完成选择后取得连续奖励，PPO和GAE据此调整选择概率，空集合得0。

两层通过D连接。计算时固定本批起点档案和上层参数，独立生成候选，批末统一更新档案。

## 三 训练分三步

1. **先训练下层。** 用扰动及恢复样本预训练扩散编辑器，再按单因子质量和成本进行PPO训练，生成候选。
2. **再训练上层。** 固定下层和候选池，提供独立历史验证指标。上层尝试不同子集，按等权组合的后续表现学习搭配。
3. **最后交替训练。** 固定上层，计算D并更新下层。再用更新后的下层生成新候选，重新采集选择轨迹并更新上层。

保存入选公式、使用方向、等权系数、各阶段指标及模型版本。

## 五 对比实验按什么顺序做

所有学习组先采用3个训练种子，使用相同股票、日期、起点库、门槛和评价代码。对照组从相同初始化开始，追加训练预算一致。

| 顺序 | 具体对比 | 要回答的问题 |
|---|---|---|
| 1 先检查数据和程序 | 核验标签时间、公式合法性、等权计算、去重及旧动作概率重放 | 结果是否可信 |
| 2 单独检查下层 | 随机合法编辑、仅结构预训练，以及同一下层结构分别使用旧奖励和新质量成本奖励 | 新奖励是否提高合格非重复候选数及后续达标率 |
| 3 单独检查上层 | 同一冻结候选池上的随机选择、按IC排名、相关性过滤后排名、前向选择加交换、上层PPO、监督集合评分加搜索 | 上层PPO能否比普通筛选和搜索选得更好 |
| 4 检查两层连接 | 两层独立训练、只继续训练下层、η＝0交替训练、η＝1交替训练 | 继续训练、上层更新及组合贡献反馈各自有多大收益 |
| 5 检查速度和组合规则 | 相同策略下逐项启用缓存和批量计算，比较2步与4步编辑，同一选中集合比较等权与Ridge | 提速是否提高实际产出，配权是否影响结论 |
| 6 最后整体比较 | 原双层PPO、新下层加最佳常规筛选、新双层PPO | 新分工是否有效，两层各自是否提供增量 |

普通筛选和搜索使用同一可见验证段及其内部时间划分挑选成员，各组统一等权评分，最终测试段用于验收。速度优化同时检查固定尝试数和固定墙钟时间，重复、失败及预计算成本计入预算。

主要记录固定时间内的合格非重复因子数、后续达标数、等权组合IC和RankIC、跨时期稳定性，以及统一交易规则下扣除成本的表现。逐项保存耗时，确认收益来自生成质量、筛选能力还是计算速度。

## 六 两周训练安排

以公司RTX 4060为主训练设备，CPU并行执行公式评价，先核对显存、CUDA和实际吞吐。按单机顺序运行安排14天，训练占约11个设备日，其余时间用于准备、最终评价和汇报。

| 时间 | 工作与训练预算 |
|---|---|
| 第1至2天 | 更新2026年行情，生成标签和滚动任务，完成新分工实现及运行检查，测量每小时更新量 |
| 第3至6天 | 下层长训练共96小时。同一结构使用旧奖励和新奖励两组，各3个种子，每个模型约16小时。随机编辑与结构预训练结果作为参考 |
| 第7至10天 | 上层训练共96小时。集合PPO和监督集合评分模型两组，各3个种子，每个模型约16小时。固定下层，复用相同候选池 |
| 第11至13天 | 联合验证共72小时。只继续训练下层、η＝0交替训练、η＝1交替训练三组，各3个种子，每个模型追加约8小时。独立训练的双层模型同时保留作对照 |
| 第14天 | 固定模型完成测试，汇总速度、有效因子和组合表现，保存曲线与案例，整理汇报 |

主模型每个种子累计约40小时，完整对照组累计约264个设备小时训练。各阶段记录真实候选数、更新数、GPU使用率、耗时和开发表现。每2小时保存检查点，并在约2、4、8、16小时等预设节点检查开发曲线。相同对照组使用一致的检查点选择规则。

默认执行14天计划。若压缩为7天，先完成数据检查及上下层独立长训练，依据曲线安排后续联合训练。训练奖励和开发表现共同用于判断是否值得追加训练，最终保留测试在模型与参数固定后执行。

## 七 本轮要得到的结果

形成三项明确结论。第一，新下层是否更快产生合格候选。第二，上层是否在相同候选池上选出更好的等权组合。第三，组合贡献反馈是否改善最终系统。汇报附各组训练时长、设备、实际数据范围、种子差异、训练曲线和最终因子清单。
