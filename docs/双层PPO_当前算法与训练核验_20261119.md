# 双层PPO当前算法与训练核验

核验日期：2026年11月19日。当前运行入口为 `single_factor.hierarchical.comparison_cli`。本文件区分实现是否符合定义、参数配置是否落地、金融效果是否已经验证，三者不能相互替代。

## 结论

模型规模和阶段预算可以按代码实测确认；学习率、网络规模和训练预算仍是初始配置，没有证据证明已经最优。此前CPU回归和小规模GPU流程不能证明256宽模型在真实行情上长期稳定。本轮发现并修复了起点池接纳重复信号的缺陷；真实GPU的失败检查点仍须完成针对性审计，再启动多天训练。

## 用户本次确认的算法定义

| 项目 | 当前口径 |
| --- | --- |
| 下层动作 | 最多32个短名单起点或NEW。扰动起点后按概率选RPN子式位置与合法替换，也可保持原式或选STOP结束 |
| 合法性边界 | 节点最多15、深度最多8、回看最多100交易日，类型及动作掩码约束 |
| 起点池 | 初始公式及生成、达标、去重的公式；G段信号完全相同的新公式不重复入库 |
| 候选准入 | G段IC≥0.02、RankIC≥0.01、ICIR≥0.10、覆盖率≥0.80 |
| 上层动作 | 主配置候选容量512，每次建池尝试2048次。先按概率决定STOP或继续，继续时再从未选候选中选一个。选尽自动结束，组合无固定成员上限。 |
| 信息边界 | F定方向，G生成准入，A提供上层观察，R计算训练奖励；相邻段标签成熟后衔接 |
| 配权 | 方向固定，每天截面标准化，入选成员等权 |
| 股票范围 | 公司库实时准备面板时默认查询日期范围内的全部股票。股票名单、数量和来源记入面板，所有实验使用同一面板。|

独立下层奖励：`R_L = Q − κC`。交替训练下层奖励：`R_L = Q − κC + D`。κ初值0.05。Q为三个有向指标相对门槛的裁剪裕量均值，扣除覆盖不足；非法或不可计算时Q=-1。C为实际生成评价耗时除以锁定参考耗时。

下层的当前公式只有在策略选择STOP时才成为终点。反向编辑不限次数，结构预训练与起点扰动的步数是独立参数。每轮通常收集16次生成尝试，它们的编辑次数由策略决定。

新协议在选定并扰动起点后记一次初始质量。每个编辑的即时奖励只记 `Q(修改后) − Q(修改前)`，保持原式得0。STOP统一扣除整条轨迹的成本，不再发放质量分。初始质量和各步质量差加起来等于最终质量，所以轨迹总奖励仍是 `Q − κC + ηD`。

对已执行的编辑，按更新前策略给下一步全部合法动作加权。价值网络预测最终质量减剩余成本，计算编辑后的后续回报时减去该状态已经计入的质量和已耗成本。这样可在新的逐步奖励口径下计算优势，也无需逐个重算未走到的公式。交替阶段把主提案的实际成员贡献D加到策略的学习信号。辅助评分只使用F/G数据，批次日志 `edit_continuations` 记录参与计算的状态、下一步合法转移数和耗时。

上层奖励：`R_U = α平均IC − β块波动 − γH`，初值α=50、β=25、γ=0.5。R段每天计算组合信号与未来20日收益的截面IC，再跨日平均；每10日取块均值，并计算块均值总体标准差。

H按R段每个成员的IC、RankIC、ICIR和覆盖率欠缺度计算，先对四项平均，再对成员平均。单项欠缺度为 `clip((门槛−实际值)/门槛, 0, 1)`。搜索段已全部达标的入池成员，其搜索段H为0，因此不能用搜索段H检查后续退化。本次用户明确选定反馈段，旧稿中搜索段的表述不再作为当前口径。

D由上层评价器计算：固定已经选中的组合，移除该成员，其余成员重新等权，完整组合效用减去移除后的效用。它是当前组合的局部贡献，不是全因子池重新挑选的差值。独立下层有效系数为0，交替阶段为1；未选或未入池提案没有对应贡献时D=0。日志记录 `eta_effective`。旧基础版本η=0的结果保留其原定义，不能事后称为已启用D的训练。

主实验先做结构预训练，再训练下层。下层冻结后，各任务用固定候选池训练上层。进入交替阶段，当前下层生成主提案，与该任务已有的池内候选一起由冻结上层挑选。只把属于本批主提案的D反馈给下层。下层更新后丢弃这次用于计算D的上层轨迹，按新下层重新生成候选池并重新采上层轨迹，再更新上层。R段的奖励数据不进入上层观察，也不进入下层起点统计。

## 时间与续训

`primary`首轮预算为下层48小时、上层24小时、交替48小时，总计120小时，当前先运行种子0。预训练、候选池准备和保存耗时另计，并在完整更新边界检查预算，因此不等于恰好五天墙钟时间，也不代表到时一定收敛。

下层每批采集16次真实生成回合，包含起点及实际编辑到STOP的动作。上层每批采集4次组合选择回合。PPO 对每批数据优化4轮，每个优化小批至多16条动作记录。主配置对单训下层、单训上层及交替阶段分别设有100万批或轮的保护上限，并在先达到时间或轮数时停止。交替每轮更新下层一次和上层一次，并把重建候选池的时间计入该阶段。进入上层独立训练前的建池时间和检查点保存时间不在120小时内。实际完成数以各节点 `progress.json` 的 `lower_iteration`、`upper_iteration`、`continuation_iteration` 为准。

到预算或中断后可以从检查点接续。`extend`继承权重、优化器及动量、随机状态、候选池和累计轮数；新增轮次保留原结果。延长下层后先刷新相应生成器版本的候选池，再训练上层。重复同一轮续训命令用于恢复，不重复追加预算；下一次加时使用下一轮目录。

## 本次发现的问题和验证边界

1. GPU报错为旧动作对数概率重放差异约4.9591e-5，超出2e-5检查阈值。采样与合并批次使用不同矩阵形状，数值漂移是待真实检查点验证的原因，不能仅凭数值小就认定误报。当前修复按原采样路径逐条复核，原单条阈值保留；批量偏差上限及非有限值检查仍有效，旧动作概率不被重写。
2. 起点池此前仅检查eligible，候选池拒绝的重复信号仍可能入起点池。本轮修复为同时检查重复标记及本任务已知信号身份，覆盖同批、跨批和旧检查点字段补齐。
3. 此前D默认关闭，属于基础版本；本次根据用户明确选择改为交替阶段权重1，单独下层权重0。H明确保留反馈段。奖励定义有变时必须使用标注清楚的新协议，不能悄悄改写旧实验。
4. 新颖性有/无对照尚未接入当前新主算法的比较节点。硬去重不能替代新颖性奖励或相关性约束的消融。旧架构search中的新颖性实现不代表新主流程已有该对照，因此完整实验计划尚未全部实现。
5. 训练与算法对比按用户要求共用2025—2026年任务，结果标记为训练期表现；不能据此声称未来选股盈利已验证。股票池和复权等数据约定当前仍为exploratory。

概率校验修复的前轮全量CPU回归179项通过、5项GPU相关跳过，后续恢复链路另测3项通过。本轮针对起点池去重、D分阶段权重、数据协议、训练恢复及各比较节点的相关回归64项通过、4项GPU相关跳过。尚未收到公司RTX4060上修复后的真实失败检查点验证结果，不应放行多天训练。D权重启用也不保证每批产生非零贡献，需观察入池、入选及实际贡献记录。

## 公司机器的真实检查点审计

`--device cuda` 启动前核验当前训练 Python 能访问所选 CUDA 设备，并校验确定性 CuBLAS 工作区设置。旧动作概率按优化小批大小重放，全批校验通过后才允许优化。神经网络在指定设备上运行，行情求值和候选池相关性计算仍主要在 CPU。所有股票与增大的建池预算会增加实际耗时，真实设备的显存峰值和批耗时须用新协议实测。

当前 `test_ppo_replay.py` 的宽度256用例可检查带下层STOP的更新和512候选规模的上层更新。公司机器用训练环境执行该测试，CUDA 用例跳过时须先检查解释器和显卡驱动。新版全市场、逐步质量奖励和上层STOP须另跑新短协议。已有检查点测试只处理旧协议相同配置下的恢复验证。

加入分批重放和 CUDA 启动检查后，相关回归 58 项通过、5 项跳过。本机 CPU 以宽度 256、完整文法和 500 只合成股票完成下层一批训练。16 次生成尝试产生 465 条动作记录和 120 次优化器更新，旧策略对数概率最大复核误差为 9.54×10⁻⁷。宽度 256、512 个候选的上层 PPO 更新也通过了 CPU 测试。公司训练机仍需验证 CUDA、真实全市场面板耗时和显存峰值。
