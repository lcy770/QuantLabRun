### 4.2 为什么引入AST编辑扩散

直接依据的论文为 **Diffusion On Syntax Trees For Program Synthesis**，arXiv 2405.20519，ICLR 2025正式收录。此前阅读的是2024年预印本。

借鉴的机制是对合法语法树进行局部子树替换，构造可逆扰动，学习反向去噪。对于已有较好公式，希望局部编辑能提高一次生成的命中率，并保持完整子表达式合法。

原论文有目标观察和监督信号。金融任务没有唯一正确的目标因子，结构预训练只提供编辑初始化，金融效果需要真实奖励训练和对照。AST结构本身也需要承担动作枚举、检查和转换成本。

[arXiv](https://arxiv.org/abs/2405.20519) · [ICLR正式论文页](https://proceedings.iclr.cc/paper_files/paper/2025/hash/666dd0d92a64396e753c691db93493d4-Abstract-Conference.html)

```latex
R_L(f)=0.5|IC_{fit}(f)|+0.3|RankIC_{fit}(f)|+0.2\tanh(|ICIR_{fit}(f)|)
```

## 5 当前完整算法定义

本节是新方案拟用设计，供后续实现。旧运行结果对应第4节与第8节的历史架构。

### 5.1 下层起点池与生成过程

起点池是供下层继续修改的合法公式库，包含初始合法公式和已生成、达标且去重的公式。NEW从固定文法先验产生新的合法起点。起点池拟在批末更新，避免一批中途改变动作支持。

下层轨迹为选择起点 → 固定正向扰动 → 若干次原生RPN反向编辑 → 真实评价 → 合格且去重后入候选池。扩散模型是被下层PPO更新的生成策略。

下层状态拟包括起点内容与已有指标、当前RPN词元、剩余编辑步数、任务背景和计算预算。较详细研究稿还建议保存档案和模型版本。最终网络结构与必要输入需通过短实验收敛。

### 5.2 下层动作空间

起点动作从M个合法起点与NEW中选择。当前动作说明草案拟用M≤32。

编辑动作选择一个完整RPN子式区间 `[l,r)`，再选择合法替换子式v，另含NOOP保持原式。先选位置再选替换，两者联合概率用于PPO。替换可改变变量、算子、常量或窗口，也能扩大或缩小子式。

例 `close open sub` 将区间 `[1,2)` 的 `open` 替换为 `high`，得到 `close high sub`。执行通过词元区间拼接完成。

拟比较2步与4步编辑。NOOP消耗一步。合法性掩码检查完整子式、操作数类型、量纲、长度、深度和回看。说明稿沿参考配置给出词元数≤15、深度≤8、累计回看≤100日，均属于首轮边界，需要按配置登记。

结构预训练必须检查逆向动作处于当前合法支持中。固定正向扰动核时，PPO记录起点及真实反向动作的概率。条件分解的对数概率相加。

### 5.3 下层质量与成本奖励

基础奖励为

```latex
R_L=Q-\kappa C
```

单因子质量使用搜索段G上的有向IC、RankIC和ICIR。方向由更早F段确定并锁定。

```latex
s(x,\tau)=\mathrm{clip}\left(\frac{x-\tau}{\tau},-1,1\right)
```

```latex
Q=\frac{s(IC,\tau_{IC})+s(RankIC,\tau_{RankIC})+s(ICIR,\tau_{ICIR})}{3}-\max\left(0,\frac{\tau_c-c}{\tau_c}\right)
```

门槛初稿为IC 0.02、RankIC 0.01、ICIR 0.10、覆盖率0.80。门槛与奖励权重分别设定。ICIR使用日IC均值除以日IC标准差的未年化口径。

公式非法、指标不可计算或规范化公式完全重复时，简稿规定Q=−1。覆盖不足连续扣分。生成入池仍要求全部门槛通过，连续训练分数允许失败候选获得不同反馈。

```latex
C=\frac{t}{t_{ref}}
```

t覆盖选起点、扰动编辑及评价耗时。参考耗时为训练前基准任务的中位耗时，校准后锁定。κ曾暂取0.05，尚无标定结论。真实训练、辅助续采样、缓存准备和在线搜索成本分开保存。

同一终点评分训练起点选择和编辑。新颖性奖励及组合贡献D作为单独消融，不默认写入基础版本。

### 5.4 上层状态与动作

上层面对本任务冻结的候选池。观察独立历史验证段A中的单因子IC、RankIC、ICIR、覆盖率、稳定性、候选间相关性，以及已选成员和剩余名额。

候选间相关性拟采用逐日共同有效股票上的有向Pearson，再跨日平均并保留符号。研究长稿还提出语法表示、复杂度、成本和集合注意力，这些属于候选实现方案，最小版按实际增益选择。

上层每步从未选候选中选1个，或STOP。已选成员屏蔽，达到Kmax后结束。动作说明稿拟用N≤128、Kmax=10，初始最多129种动作。早期长稿的Kmax=16已被后续简稿的10替代。

上层学的是“已选这些因子后，下一个成员是否能改善完整组合”，以及何时停止。单独IC排名无法直接表达随已选集合变化的互补关系。上层PPO的必要性由同池常规筛选和其他学习算法的对照检验。

### 5.5 等权组合与评价口径

使用更早F段确定每个因子的方向，IC非负取+1，否则取−1。每日在股票截面标准化后，按1/K等权组合。

```latex
P_{t,i}=\frac{1}{K}\sum_{j=1}^{K}z_{j,t,i}
```

z为方向固定并标准化后的因子值。成员指标和覆盖率在缺失填充前统计。11月12日拟用规则为标准化后缺失值及零方差信号记0，等权保持1/K。组合每日IC不可计算时记0并记录比例，空集合奖励为0。上述边界处理尚需实现及回归核验。

新方案评价选完的完整集合，允许多次选择形成互补结构。旧的逐个候选加进当前组合、只有即时改善才接纳的做法属于旧架构。

### 5.6 上层怎样训练

先冻结下层，准备多个历史任务的候选池和验证特征。每回合从空集合开始，按上层概率依次选择成员或STOP。只用截至A结束已成熟的信息决策。

选择完成后，在历史反馈段R计算组合预测和稳定性评分，加上成员质量及数量扣分，得到连续终点奖励。PPO据回报、Critic和优势更新成员与STOP概率，随后重新采集新轨迹。

基础版本中间选择奖励可为0，最终连续得分反馈整条选择轨迹。终点奖励是连续值。研究稿中的势函数整形是后续可选降方差方案，尚未成为必需结构。

### 5.7 两层训练与连接

顺序为先训练下层 → 冻结下层及候选池训练上层 → 比较分别续训和交替续训。

交替时冻结另一层版本，重新生成候选并采集当前策略的上层轨迹。下层参数更新后，上层使用新下层产生的经验。采样和PPO更新使用一致的动作支持、条件、池版本和概率。

基础连接通过候选池完成，最终系统同时考察单位时间合格候选产出与最终组合效果。两层数学上完全共享一个目标的严格推导，仅在特定跨层信用条件下成立，不能由“交替训练”直接推出。

## 6 最新上层奖励公式与WPS写法

### 6.1 总奖励

```latex
R_U=\alpha\overline{IC}-\beta\sigma_{block}-\gamma H-\delta\frac{K}{K_{max}}
```

α、β、γ、δ分别控制预测、稳定性、成员质量和数量。符号γ在这里表示成员质量权重，PPO折扣另行命名。

### 6.2 用户最后要求重写的三项

组合预测分

```latex
S=\alpha\frac{1}{T}\sum_{t=1}^{T}IC_t
```

每天用组合信号与未来20日收益计算股票截面Pearson相关ICt，在评价段T天取平均。

稳定性扣分

```latex
L_s=\beta\sqrt{\frac{1}{B}\sum_{b=1}^{B}(u_b-\bar{u})^2}
```

每10个交易日为一块。ub为该块平均组合IC，ū为所有块均值的平均，B为块数。使用总体标准差。20日反馈段只有两个块。

成员不达标扣分

```latex
L_q=\gamma H=\frac{\gamma}{4K}\sum_{j=1}^{K}\sum_{m=1}^{4}\mathrm{clip}\left(\frac{\tau_m-x_{j,m}}{\tau_m},0,1\right)
```

按最后用户提供的表述，xjm为成员j在搜索期的IC、RankIC、ICIR和覆盖率，τm为对应门槛，K为成员数。clip限制在0至1，不可计算项欠缺度记1。

以上三条是当前对话最后确认的写法。用户要求简洁，每项一个公式即可，符号解释控制字数。

### 6.3 系数来源与旧数值对应

旧写法为平均IC除0.02、稳定性乘0.5再除0.02、成员质量乘0.5、数量乘0.05。0.02最初是参照拟定IC门槛量级设置的归一化尺度，使IC为0.02时预测项为1分。0.5等是独立人工权衡。

将尺度吸收到权重后，α=1/sIC，β=λ稳/sIC，γ=λ质，δ=λ数。沿旧初值可得到α=50、β=25、γ=0.5、δ=0.05，交给老师的主公式按用户要求使用字母。

这些数值尚未通过实验标定，来源是设计假设。先用训练期检查各项量级，再用开发期消融与小范围调参，固定后验收。

旧算例为平均IC0.03、块波动0.005、H0.20、K5、Kmax10，对应奖励1.5−0.125−0.10−0.025=1.25。它只验证算术。

### 6.4 成员质量项仍有一个实质问题

下层候选若已经要求搜索期四项全部达标，上层又用相同搜索期、相同门槛计算H，正常入池成员的H将为0。此时成员质量项无法提供额外训练信号。

这是当前设计中需要检查的逻辑后果。最新用户明确写搜索期间指标，交接按这一表述保留。后续需解释该项的实际作用，再讨论是否用独立验证或历史反馈段评价，或将其作为准入审计项。任何变更需说明理由并记录，避免再次默默切换数据段。

## 7 组合贡献D的完整来龙去脉

### 7.1 最初的整池移除方法

先固定同一上层版本，完整池C多次选组合取平均效用；移除提案f后在新池重新选择，再取平均。两者之差为D。初稿各重复2次，单训下层时η=0，联合时曾提出η=1作为初值。

长研究稿给出固定批背景、提案条件独立时的反事实基线推导。其前提包括固定档案、固定上层、固定提案预算、保留失败与重复来源、批末提交档案。PPO裁剪和有限采样仍有近似误差。

这个量衡量特定上层选择器可利用的整池价值，因可替代候选而很小。大池差分还可能受重选噪声与计算成本影响。用户对这一点提出了明确质疑。

### 7.2 最近采用的成员贡献解释

先让上层选出集合S，对其中一个成员f计算

```latex
D(f;S)=U(S)-U(S\setminus\{f\})
```

U为同一评价期的上层完整组合得分。移除后其余成员保持固定，重新等权，K随集合大小变化，Kmax保持配置值。剩余为空时沿用空集合效用0。

计算由上层评价模块负责。若后续做反馈，则下层奖励试验写为Q+ηD−κC，基础版η=0，η>0需配对验证。未入池或完全重复提案的贡献在早期讨论中设为0，具体来源归因仍须登记。

固定已选集合移除与整池重选评价不同。长研究稿中的无偏基线论证依赖原整池定义，不能直接移到只对已选成员计算D的方案。该贡献是局部解释量，其是否能改善生成器仍待实验。

### 7.3 尚未解决的连接问题

上层选中的成员才能直接获得上述局部贡献，未选候选如何反馈、重复来源如何分配、是否需要采样多个组合以及反馈成本，都未完成实现验证。用户希望换计算方法来降低噪声，后续应先用固定集合或合成问题核验信号，再训练。

### 7.4 早期长方案的数学联系及其适用范围

早期方案把下层生成的候选池记为C，上层参数为φ，定义池的可选价值为同一上层采样组合后效用的期望。

```latex
V_\phi(C)=E_{S\sim\pi_\phi}[U(S)]
```

系统目标是在生成分布上同时提高该价值、单因子质量、新颖性并降低成本。冻结下层时，后三项不随上层动作变化，上层优化U。冻结上层时，下层用整池差分D及自身质量成本反馈。

整池移除基线的推导要求C移除当前提案后的结果与该提案采样独立。固定微批背景并独立采样各提案时，这一基线项的期望策略梯度为0，能从整池价值中扣掉不受当前提案影响的部分。实际PPO裁剪与有限采样仍需单独评价。

初稿拟用16个新提案和最多112个背景成员，每个池值采样2次，最多34次完整集合评价。该规模用于估算成本，未证明其信噪比足够。

后来改成固定已选集合内的成员移除后，上述提案独立基线条件需要重新讨论。主方案现阶段将两层各自任务验证清楚，再检验闭环。新窗口可从研究稿第9节读取原始推导。

## 8 已完成实验与主要结果

### 8.1 评价名词

- 搜索发现数为搜索段通过合法性、质量与去重的新增候选数。

| 用户问过的词 | 当前应采用的解释 |
|---|---|
| 单次模型训练 | 一个训练种子得到一套参数，多次搜索复用它 |

| GAE | 用实际回报和Critic估计优势，控制PPO梯度方差，属于更新方法 |
| 多次续采样 | 固定当前动作后按旧策略完成余下编辑，平均真实终点评分估计Q |
| 扩散与PPO | 扩散定义生成分布与去噪动作，PPO根据金融反馈更新其策略参数 |

| RPN编码加树编辑 | 用序列网络表示公式，执行仍走树编辑 |
