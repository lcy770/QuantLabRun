## 根据运行结果做的修改

1. 下层先抽编辑位置，再只计算该位置的替换概率；训练重放仍计算完整联合概率和精确熵，不改变策略分布或 PPO 目标。
2. 下层奖励独立只读拟合期数据，续采样复用标量缓存，减少无关市场计算。
3. NEW 排除已用起点及已知结果，保留结构和信号两级去重。
4. 组合比较复用拟合期 Gram 矩阵和搜索期每日协方差。成本计数放在公共评价器中，涵盖配对去重、失败替换和超时评价。
5. 补充三次独立训练的 suite 入口；统计先在同一训练种子内汇总，再跨训练种子比较。
6. 增加每阶段训练成本、每种对照的从头训练成本与端到端速度记录；新增因子数量仍显式进入上层奖励。
