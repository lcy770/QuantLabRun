# 双层PPO算法方案

下层生成合格因子，上层选择适合等权组合的成员。

![算法总览](D:/Projects/Python/QuantLab-backtest/docs/双层PPO算法总览_20261112.png)

## 下层PPO

起点池包含初始公式和已有合格公式，并保留新建选项。下层根据公式及已有指标学习选择概率，再用RPN扩散编辑，合法、达标、去重后入池。

**R下层 = Q + ηD − κC**

Q按IC、RankIC、ICIR距门槛的程度连续给分，覆盖不足或公式无效扣分。C为生成评价耗时÷参考耗时，η、κ为权重。

生成结果的下层奖励，同时训练起点选择和扩散编辑。

## 上层PPO

观察独立验证指标、因子间相关性和已选成员，逐个选择或停止。方向提前固定，标准化后每个成员权重为1/K，K为入选数量。

**R上层 = 组合预测分 − 稳定性扣分 − 成员不达标扣分 − 数量扣分**

预测分看后续组合IC，跨期波动大、成员不达标或数量过多均扣分。选完后给连续奖励，训练因子搭配能力。

## 两层怎样连接

**D = 全池选出的平均分 − 移除该因子后重选的平均分**

固定同一上层，完整池与移除某因子的池分别多次选择，取平均分。移除后得分下降越多，D越大，生成该因子的下层获得更多奖励。

先单独训练下层，再固定候选池训练上层。最后交替，先固定上层计算D并更新下层，再用新候选更新上层。
